# DVE Marketing and Business Management

Rebuild of dvembm.com (Traverse City, MI business incubator — part of The DVE Project) as a single-page React (Vite) site, prepped for Netlify + GitHub.

- Copy lives in `src/data/content.js`; images in `public/img/` (see PHOTO-CREDITS.md).
- Contact form posts to Netlify Forms (form name `startup-inquiry`).
- Run locally: double-click `start.bat` → http://localhost:5180
